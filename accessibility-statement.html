Accessibility Statement

Source Accessibility Ltd is committed to ensuring digital accessibility for people of all abilities[cite: 2, 59]. We continually improve the user experience for everyone and apply the relevant accessibility standards[cite: 2, 59].

Conformance Status & Standards

The Web Content Accessibility Guidelines (WCAG) 2.2 Level AA defines requirements for designers and developers to improve accessibility for people with disabilities[cite: 2, 59, 62].

This website is fully conformant with WCAG 2.2 Level AA[cite: 2, 59]. Fully conformant means that the content completely conforms to the accessibility standard without any known exceptions or barriers[cite: 2, 59].

Technical Specifications & Compatibility

Accessibility of this website relies on the following technologies to work with the particular combination of web browser and any assistive technologies or plugins installed on your computer[cite: 2, 59, 62]:

  • HTML5 (Semantic Landmarks & Standard Controls)[cite: 59]
  • WAI-ARIA (Where semantic native HTML is insufficient)[cite: 59, 62]
  • CSS (High-contrast focus appearance, reflow up to 400%, flexible typography)

Testing & Evaluation Approach

This website was built from the ground up using a clean, static HTML/CSS architecture[cite: 59]. It has been evaluated through manual technical testing and real assistive technology sweeps, including[cite: 2, 61, 62]:

  • Keyboard-only navigation: Ensuring full logical focus order, visible focus rings (minimum 3:1 contrast), and zero focus traps[cite: 30, 59, 62].
  • Screen Reader validation: Verified using VoiceOver (macOS/iOS) and NVDA (Windows) across structural landmarks, headings, and interactive elements[cite: 2, 61, 62].
  • Screen Magnification & Reflow: Tested up to 400% zoom with no horizontal scrolling or content overlap[cite: 30, 62].
  • Voice Control: Verified that visible link and control labels match accessible names for hands-free operation[cite: 30, 61, 62].
